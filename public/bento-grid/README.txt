This folder is created to store the images for the Zoom Parallax (Bento Grid) section. 

To use your own images:
1. Place 7 high-quality images in this folder (e.g., image1.jpg, image2.jpg, ... image7.jpg).
2. Open `src/App.tsx`.
3. Locate the `parallaxImages` array.
4. Replace the unsplash URL links with the relative paths to your images, like this:
   `{ src: "/bento-grid/image1.jpg", alt: "Description" }`
